# Source data

Download **Online Retail.xlsx** from the [UCI Online Retail dataset](https://archive.ics.uci.edu/dataset/352/online+retail) and place it in this directory, keeping the filename exactly as shown.

Citation: Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository. DOI: [10.24432/C5BW33](https://doi.org/10.24432/C5BW33). Dataset license: CC BY 4.0.

The source workbook contains 541,909 transaction lines and eight columns, covering 1 December 2010 to 9 December 2011. Unit prices are in GBP. One row is a transaction line, not an entire order. The raw workbook and large derived transaction CSVs are excluded from Git; notebooks regenerate the CSVs. Small summary tables remain in the repository.

The source workbook is preserved as supplied. Local audit results, rather than the dataset website's missing-value metadata, govern missing-value handling in this project.
